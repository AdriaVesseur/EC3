# Fotos del catálogo

Las fotos de ejemplo se han copiado directamente de los ZIP publicados de cada paquete: `test-car.jpg` (preview de KTM), `safety-car.jpg` (preview de BMW) y `paul-ricard.png` (preview del circuito). Puedes sustituirlas por las fotos de tu competición o añadir otras aquí.

En `manifest.json`, `image` contiene el enlace HTTPS Raw de la foto; `icon` contiene el enlace del logo pequeño. Son recursos visuales, no archivos que se instalan en Assetto Corsa. Para publicar imágenes nuevas, usa material que puedas distribuir.
